# Black Orchide — e-commerce starter (Django)

Petit projet starter pour un site e-commerce nommé "Black Orchide".

Instructions (PowerShell):

1. Créer et activer un environnement virtuel (optionnel mais recommandé):

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. Installer les dépendances:

```powershell
python -m pip install -r requirements.txt
```

3. Exécuter les migrations et lancer le serveur:

```powershell
python manage.py migrate
python manage.py runserver
```

Le site sera accessible sur http://127.0.0.1:8000/ .
